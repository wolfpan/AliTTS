# AliTTS 语音工作台

基于 **Vue 3 + Node.js** 的本机/内网语音合成（TTS）Web 应用，接入阿里云百炼（DashScope）语音合成、声音复刻与声音设计服务。

![Node](https://img.shields.io/badge/Node.js-%3E%3D18-339933) ![Vue](https://img.shields.io/badge/Vue-3-42b883) ![License](https://img.shields.io/badge/License-Apache--2.0-blue)

## 功能特性

### 🎧 语音合成
- **快捷模式**：新闻播报 / 有声书 / 客服 / 短视频口播等 9 个场景模板，三步出声；支持保存自定义模板
- **高级模式**：全参数控制——语速 / 音调 / 音量 / 采样率 / 码率 / 随机种子 / 语言提示
  - **自然语言指令**：如"用温柔的语气，语速稍慢一点"（Qwen-Audio 系列）
  - **SSML 助手**：可视化插入停顿 `<break>`、多音字 `<sub>`、拼音标注 `<phoneme>`、音效 `<soundEvent>`、数字读法 `<say-as>`
  - **纠音（hot_fix）**：拼音标注纠正发音 + 敏感词替换
  - **词级时间戳**：每个词的开始/结束时间，适合字幕对轨
- **长文本自动分段**：按句切分、顺序合成、自动拼接（WAV 剥头重拼 PCM，段间静音可调 0–500ms）
- **流式边收边播**：单段 WAV/PCM 时音频边到达边播放，无需等全部合成完
- **A/B 对比**：最近两次生成并排回放 + 参数差异高亮，一键应用 A 的参数重新生成

### 🎙️ 声音复刻
- 上传音频或浏览器直接录音（10–20 秒）
- 浏览器端自动解码、转 24kHz 单声道 WAV，无需本地转码工具
- 创建后自动轮询状态（DEPLOYING → OK），支持试音、更换样本、别名、删除

### 🎨 声音设计
- 用一段文字描述想象中的音色（性别 / 年龄 / 情绪 / 语速 / 场景组合生成器）
- 创建即返回试听预览，满意再入库
- 自定义音色（复刻/设计）在高级模式音色抽屉中按模型过滤使用

### 📚 其他
- **历史记录**：本地落盘（含音频），回放 / 下载 / 一键载入参数复现 / 词级时间轴
- **主题**：浅色 / 深色 / 跟随系统
- **局域网共享**：可开启局域网访问 + 访问令牌保护 + 端口设置

| 模型 | 系统音色 | 复刻 | 设计 | 自然语言指令 | SSML | 纠音 | 备注 |
|---|---|---|---|---|---|---|---|
| qwen-audio-3.1/3.0-tts-plus/flash | ✓ | ✓ | ✓ | ✓（自由） | ✓ | ✓ | 支持内联情感标签 `[excited]` 等 |

## 快速开始

### 环境要求
- Node.js ≥ 18
- 一个阿里云百炼（DashScope）API Key（[获取方式](https://bailian.console.aliyun.com/)：百炼控制台 → API-KEY 管理，需先开通语音合成服务）

### 安装与启动

```bash
# 1. 安装依赖（根目录 + 前端）
npm install
npm --prefix web install

# 2. 日常使用（推荐）
npm run build      # 构建前端
npm start          # 打开 http://127.0.0.1:3210

# 开发模式（热更新）
npm run dev        # 前端 http://127.0.0.1:5173，API 代理到 3210
```

首次打开会进入**配置向导**：填入百炼 DashScope API Key → 连通测试 → 偏好设置 → 进入工作台。

### 密钥与数据存放

- API Key **只保存在本机服务端** `data/settings.json`（已被 `.gitignore` 排除），浏览器端仅见掩码
- 历史记录与音频文件保存在 `data/` 目录（`history.json`、`audio/`）
- 配置文件结构参见 [`docs/settings.example.json`](docs/settings.example.json)
- 支持百炼**业务空间专属域名**（向导/设置中填 Workspace ID）与**新加坡地域**

## 局域网部署（可选）

在「设置 → 服务」中：

1. 开启**允许局域网设备访问**（监听 `0.0.0.0`）并重启服务；页面会列出本机所有内网地址（如 `http://192.168.x.x:3210`），点击复制发给同事
2. 建议设置**访问令牌**：设置后所有 API 请求需携带令牌——浏览器首次访问会弹窗输入一次并记住，音频直链以 `?token=` 参数携带；令牌**即时生效**，无需重启
3. 可自定义**端口**（1024–65535，需重启）
4. 首次开启时 Windows 防火墙可能弹窗，选择"允许访问"即可

> ⚠️ 本项目面向**本机/内网**场景，未做公网防护（无 HTTPS、无用户体系）。请勿直接暴露到公网。忘记访问令牌时，编辑本机 `data/settings.json` 清空 `server.accessToken` 即可。

## 技术实现要点

- **SSE 流式转发**：服务端解析 DashScope SSE（兼容公共域名单行与业务空间多行 pretty JSON 两种格式），转发为自有事件流（meta/audio/progress/words/done/error），前端边收边播
- **域名自动回退**：业务空间域名不支持 qwen3-tts 的 multimodal 端点等场景，自动回退公共域名
- **多段 WAV 合并**：剥离各段 RIFF 头拼接 PCM + 段间静音后重建单一文件头（直接拼接会损坏文件）；MP3 帧流可直接拼接
- **浏览器端样本预处理**：复刻样本用 Web Audio API 解码 → 重采样 24kHz 单声道 → 编码 WAV，上传即为合规格式
- **能力矩阵驱动 UI**：模型不支持的能力（如 qwen3-tts 无语速条、v2 无指令）自动隐藏/禁用并给出提示

## 常见问题

- **提示"未收到音频数据"**：检查 API Key 是否有效、语音合成服务是否已在百炼开通；业务空间模式请确认 Workspace ID（注意不是完整 URL）
- **多段合成后音频损坏**：已通过服务端 WAV 合并解决；如遇到请确认格式为 wav/pcm
- **浏览器无法自动播放试听**：浏览器策略要求用户先与页面交互过；点击页面任意位置后再试
- **Windows 下 curl 测试中文接口乱码**：控制台编码问题，不影响应用本身
